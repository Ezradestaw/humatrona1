About Humatron

Humatron is a privacy-focused PDF processing service that provides PDF Stealth to sanitize and optimize PDF files while preserving their visible content.

Core Purpose & Technology

When standard PDF documents are shared, they frequently carry hidden layers, embedded fonts, tracking metadata, and object trees. Through PDF Stealth, Humatron sanitizes and optimizes each page into pristine rasterized page structures. This deep-cleans hidden data, flattens text layers, and optimizes the document while completely preserving visible content and layout.

AI Detector & Plagiarism System Bypass

Automated scanners, AI detectors, and plagiarism detection systems inspect raw PDF token streams, font encoding tables, and semantic signatures. PDF Stealth defeats these detection mechanisms through:

  • Neutralizing AI Content Detectors: Applies subtle pixel-level Gaussian noise modulation and zero-width Unicode dispersion to break automated AI detection patterns while preserving crisp visual readability for humans.
  • Bypassing Plagiarism Systems: Eliminates direct scraper text extraction by flattening layers into tamper-resistant high-resolution raster images, defeating automated similarity engines.
  • Defeating Forensic & Security Controls: Strips hidden metadata, producer tags, timestamps, and embedded inspection artifacts that automated security systems monitor.

Security & Privacy Principles

  • Untrusted Input Handling: Every uploaded document is validated for MIME type, header magic bytes, and corrupted objects.
  • Isolated Processing: Document rendering occurs in isolated temporary directories with strict resource and timeout limits.
  • Strict Retention Policy: Processed files are retained for exactly 7 days, after which they are permanently deleted by automated cleanup routines.
  • No Data Exploitation: Documents are processed exclusively for PDF Stealth optimization and are never retained for machine learning or third-party sharing.
  • Authenticated File Retrieval: Downloads require user authentication and ownership authorization. No public predictable URLs are exposed.

Supported Workflow

Users register an account, verify their email address, and receive one free trial PDF Stealth processing. Further document processing is supported through flexible monthly subscriptions payable via Telebirr or Binance Pay.
