About Humatron

Humatron is a dedicated document processing utility designed to convert PDF documents into image-based PDFs reliably and securely.

Core Purpose & Technology

When standard PDF documents are shared, they typically contain selectable text layers, embedded fonts, and vector elements. Humatron converts each page into an exact raster image and reconstructs a new PDF structure. This eliminates hidden layers, flattens text into visual pixels, and prevents copying or scraping of textual content while preserving visual layout.

Security & Privacy Principles

  • Untrusted Input Handling: Every uploaded document is validated for MIME type, header magic bytes, and corrupted objects.
  • Isolated Processing: Document rendering occurs in isolated temporary directories with strict resource and timeout limits.
  • Strict Retention Policy: Processed files are retained for exactly 7 days, after which they are permanently deleted by automated cleanup routines.
  • No Data Exploitation: Documents are processed exclusively for file conversion and are never retained for machine learning or third-party sharing.
  • Authenticated File Retrieval: Downloads require user authentication and ownership authorization. No public predictable URLs are exposed.

Supported Workflow

Users register an account, verify their email address, and receive one free trial conversion. Further document processing is supported through flexible monthly subscriptions payable via Telebirr or Binance Pay.
